# DiskLens

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

DiskLens は Windows 用のディスク容量アナライザーです。ドライブやフォルダーをスキャンし、容量の使われ方を用途（アプリ、ゲーム、キャッシュ、開発プロジェクト、メディアなど）ごとに色分けしたツリーマップで表示します。間違ったものを消さずにクリーンアップできるよう手助けします。

- **速いスキャン。** 通常のスキャンに管理者権限は不要です。ローカルの NTFS ボリュームでは、MFT ディープスキャン（管理者）がマスター ファイル テーブルを直接読み、ボリュームの使用量とバイト単位で一致させます。
- **正直な数字。** ハードリンクは一度だけ数えます。スキャンで説明できない容量（アクセスできないフォルダー、ボリューム シャドウ コピー、NTFS のメタデータ）は、どこかのファイルのせいにせず「未集計」「説明できない領域」として別に表示します。
- **用途・役割・所属。** すべての項目を用途とデータの役割（プログラム、設定、キャッシュ、セーブデータ、モデルの重みなど）で分類し、根拠があれば所属するアプリ・ゲーム・プロジェクトも示します。根拠は必ず表示し、削除してよい理由としては扱いません。
- **安全なクリーンアップ。** 提案は「安全に削除可」「要確認」「削除しない · 正しい方法で」に分かれます。削除の前にすべての対象と保護の状態を一覧にします。既定はごみ箱で、完全に削除するときはもう一度確認します。保護されたシステムの場所は削除できません。
- **クリーンアップ スクリプト。**「スクリプトをコピー」で作る PowerShell スクリプトは、スキャン時からあって、その後変わっていないものだけを削除します。実行時に対象ごとにファイル ID を照合し、スキャン開始後に作成・変更・移動された項目は残します。
- **リアルタイム追跡。** スキャン後にほかのプログラムが削除したファイルは、再スキャンしなくてもマップ・一覧・検索から消えます。
- **検索。** 名前、ワイルドカード、`ext:mp4,mkv`、`size:>1gb`、`type:file`、`-cache` のような除外、`a | b` の「いずれか」、ピンインの頭文字（`wd` で 文档 が見つかります）、完全に一致しないときの近い結果（`dwnld` で download）。
- **3 つの言語。** 日本語・英語・簡体字中国語。スタート画面左上の言語ボタンで切り替えられ、選択は記憶されます。

## ダウンロード

リリースがある場合は、[Releases](https://github.com/Chrisutina/DiskLens/releases) から `DiskLens-<バージョン>-win-x64.zip` を取得し、**展開してから**中の `DiskLens.exe` を実行します。zip のウィンドウから直接ダブルクリックしても起動しません（exe だけが取り出され、隣のファイルがないため）。リリースがない場合は、以下の手順でソースからビルドしてください。

## 必要なもの

- Windows 10 または 11（x64）
- [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Microsoft Edge WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/)（最近の Windows には最初から入っています）

アカウントやネット接続は不要です。ネットにアクセスするのは、自分で始めた Web 検索だけです（選んだ項目の名前を、選んだ検索エンジンに既定のブラウザーで送ります）。

## ビルドと実行

.NET 10 SDK、Node.js、pnpm が必要です。PowerShell で：

```powershell
.\build.ps1          # Web UI を検査・ビルドし、Release のデスクトップ アプリをビルド
.\build.ps1 -Check   # さらにバックエンドのサンドボックス検査と、実際の WebView2 での結合検査を実行
```

そのあと `Start-DiskLens.cmd` をダブルクリックします（PowerShell なら `.\Start-DiskLens.ps1`）。初回はビルドするので数分かかり、2 回目からはすぐ起動します。ビルド済みなら次を直接開くこともできます：

```text
src\DiskLens\bin\Release\net10.0-windows\DiskLens.exe
```

ドライブのカードで **スキャン** を選ぶと、スキャン方法は自動で選ばれます。MFT ディープスキャンを使うには、スタート画面の右上から管理者として再起動してください。

コマンドライン：`DiskLens.exe [--scan <フォルダー>] [--mode auto|mft|walk]`

## データの保存場所

すべてこの PC の中にあり、`DiskLens.exe` の隣の `data` フォルダー（プログラムのフォルダーに書き込めないときは `%LOCALAPPDATA%\DiskLens`）に保存されます：

- `settings.json` — 表示言語
- `scan-summaries-user.json` / `scan-summaries-admin.json` — 場所ごとの最新スキャンの概要（大きい項目と識別したアプリ）。連続する 2 回のスキャンの比較に使います
- `webview2-user` / `webview2-admin` — WebView2 のプロファイル

スキャンしたファイル ツリー自体はメモリ上にだけあります。

## 開発

```powershell
pnpm --dir web check     # svelte-check
pnpm --dir web test      # 単体テストと契約テスト
pnpm --dir web dev       # 模擬データでのブラウザー プレビュー（デモモード）
dotnet run --project tools/DiskLens.Check -- all   # バックエンドの検査（.sandbox の中だけ）
dotnet run --project tools/DiskLens.UiCheck        # 実際のウィンドウを開いて操作する検査
```

ブラウザー プレビューは実際のファイルに触れず、「デモモード · 模擬データ」と表示します。デスクトップ アプリから開発サーバーを使うには `DISKLENS_DEV_URL=http://localhost:5173` を設定します（ローカルの HTTP/HTTPS アドレスのみ）。

テストがファイルを作成・削除するのは `.sandbox` の中だけです。画面の文言は `web/src/lib/locales`（中国語の原文がメッセージ ID）と、バックエンドの `L.T(...)` にあります（[docs/DESIGN.md](docs/DESIGN.md) §8.8）。設計とブリッジの仕様は [docs/DESIGN.md](docs/DESIGN.md)（中国語）にあります。

## キーボード

| キー | 操作 |
|---|---|
| `Ctrl+F` | 検索 |
| `Alt+←` / `Alt+→` | 戻る / 進む |
| `Alt+↑` | 1 つ上の階層へ |
| `F5` | 再スキャン |
| `Delete` | ごみ箱に移動 |
| `Shift+Delete` | 完全に削除 |
| `Esc` | 開いているパネルやメニューを閉じる |
